# 加油站问题 - 为什么总油量>=总消耗就能跑完一圈？

## 问题描述
LeetCode 134: 在一条环路上有 n 个加油站，其中第 i 个加油站有汽油 `gas[i]` 升。
从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 `cost[i]` 升。

## 关键结论
**如果总油量 >= 总消耗，那么一定存在至少一个起点可以完成一圈。**

## 数学证明

### 定义
- `rest[i] = gas[i] - cost[i]`：表示从站点i到站点i+1的**净收益**（或净消耗）
- `sum(rest[i]) = sum(gas[i]) - sum(cost[i])`：总净收益

### 证明思路

#### 1. 必要条件
如果 `sum(rest[i]) < 0`，即总油量 < 总消耗，那么无论从哪个起点开始都无法完成一圈。
这是显然的：总油量都不够，怎么可能跑完？

#### 2. 充分性证明（反证法）

**假设**：`sum(rest[i]) >= 0`，但无论从哪个起点开始都无法完成一圈。

这意味着：对于任意起点k，在行驶过程中总会在某个位置j处，累积油量变成负数。

即：`rest[k] + rest[k+1] + ... + rest[j] < 0`

但是，由于 `sum(rest[i]) >= 0`，我们有：
```
rest[k] + rest[k+1] + ... + rest[j] + rest[j+1] + ... + rest[k-1] >= 0
```

因此：
```
rest[j+1] + ... + rest[k-1] >= -(rest[k] + ... + rest[j]) > 0
```

这说明从j+1到k-1这段路的累积收益是**正数**，足以抵消从k到j这段的负收益。

**矛盾**：如果从j+1开始，就能用j+1到k-1这段的正收益来填补k到j的负收益，从而完成一圈。

因此，假设不成立，**一定存在至少一个起点可以完成一圈**。

## 直观理解

### 类比：银行账户
- 每个站点相当于一次交易：`rest[i]` 是这次交易的净收益（可能为正或负）
- 如果所有交易的总和 >= 0，说明"总资产"是够的
- 虽然某些交易会"亏钱"（`rest[i] < 0`），但总有其他交易"赚钱"（`rest[i] > 0`）
- 只要我们从合适的位置开始（比如从"赚钱"的交易开始），就能用赚的钱来填补亏的钱

### 关键点
- `sum(rest[i]) >= 0` **不意味着**每个 `rest[i]` 都 >= 0
- 而是说：即使有些 `rest[i] < 0`，但总和仍然 >= 0
- 所以一定存在一个起点，使得从该起点开始的累积和始终 >= 0

## 具体例子

### 例子1：可以完成
```
gas  = [1, 2, 3, 4, 5]
cost = [3, 4, 5, 1, 2]
rest = [-2, -2, -2, 3, 3]  // 总和 = 0，可以完成
```

虽然前三个站点都是负收益，但后两个站点是正收益，总和为0，可以从索引3开始。

### 例子2：无法完成
```
gas  = [2, 3, 4]
cost = [3, 4, 3]
rest = [-1, -1, 1]  // 总和 = -1，无法完成
```

总和 < 0，无论从哪个起点开始都无法完成。

## 优化算法思路

基于这个结论，我们可以优化算法：
1. 首先检查 `sum(gas) >= sum(cost)`，如果不满足直接返回-1
2. 如果满足，则只需要找到一个起点，使得从该起点开始的累积和始终 >= 0
3. 可以使用贪心策略：如果从起点i到j的累积和变成负数，那么从i到j之间的任何点作为起点都不行，应该从j+1开始尝试
